# Jaya Krishna Portfolio Website

## Project Overview
This is a responsive personal portfolio website created using HTML and CSS.  
The project showcases my profile, skills, projects, and contact section in a modern grid-based layout.

The portfolio is designed with:
- CSS Grid Layout
- Flexbox
- Responsive Design
- Gradient Backgrounds
- Modern UI Styling
- Media Queries for Mobile Devices

---

## Features

- Responsive portfolio design
- Modern gradient UI
- About Me section
- Skills section
- Projects section
- Contact form UI
- Circular profile image
- Mobile-friendly layout
- Smooth styling using CSS variables
